示例 6：工具开发最佳实践
======================================================================

✅ 好的工具设计：

1. 清晰的 docstring
   @tool
   def search_products(query: str, max_results: int = 10) -> str:
       '''
       在产品数据库中搜索产品

       参数:
           query: 搜索关键词
           max_results: 最大返回数量，默认10

       返回:
           产品列表的JSON字符串
       '''

2. 明确的参数类型
   - 使用类型注解：str, int, float, bool
   - 可选参数用 Optional[类型]

3. 返回字符串
   - 工具应该返回 str（AI 最容易理解）
   - 复杂数据可以返回 JSON 字符串

4. 错误处理
   - 在工具内部捕获异常
   - 返回友好的错误消息

5. 功能单一
   - 一个工具做一件事
   - 不要把多个功能塞进一个工具
