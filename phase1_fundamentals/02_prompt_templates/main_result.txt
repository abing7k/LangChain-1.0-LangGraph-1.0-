示例 4：多轮对话模板
======================================================================
模板结构：
  1. System: 设定角色和指令
  2. User: 第一个问题
  3. Assistant: 第一个回答
  4. User: 第二个问题（基于上下文）

生成的完整对话：
  1. [system] 你是一个Python 专家。回答要简洁、准确
  2. [human] 什么是列表？
  3. [ai] 列表是 Python 中的有序可变集合，用方括号 [] 表示。
  4. [human] 它和元组有什么区别？

AI 回复：列表和元组的主要区别：

1. **可变性**：列表可变（可增删改元素），元组不可变（创建后不能修改）。
2. **语法**：列表用 `[]`，元组用 `()`。
3. **性能**：元组比列表更轻量，访问更快。
4. **用途**：列表用于动态数据，元组常用于固定数据（如坐标、字典键等）。

示例：
```python
lst = [1, 2, 3]
tup = (1, 2, 3)
lst[0] = 10  # ✅ 允许
tup[0] = 10  # ❌ 报错
```

在我们程序员的世界里，**bug** 就是代码中的错误或者缺陷，导致程序运行得不如预期——比如点个按钮结果电脑开始播放《孤勇者》，或者输入密码时自动帮你下单了一打榴莲……（别问我是怎么知道的）

其实“bug”这个词还有个经典梗：据说早在1947年，计算机先驱格蕾丝·霍普（Grace Hopper）在她的电脑里发现了一只**真的飞蛾**卡在继电器里，导致系统故障。她把这虫子贴在日志本上，写着“First actual case of bug being found.”（第一次发现真正的bug）😂
