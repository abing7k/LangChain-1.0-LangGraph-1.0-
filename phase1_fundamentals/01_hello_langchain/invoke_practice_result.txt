问题：什么是递归？

【角色 1：专业教师】
递归（Recursion）是计算机科学中一种重要的程序设计与问题求解方法，其核心思想是：**一个函数在其定义中直接或间接地调用自身，以解决规模更小的相同问题**。

### 1. 递归的基本结构
一个正确的递归必须包含两个关键组成部分：

- **基础情形（Base Case）**：也称为终止条件，是递归调用的出口。它处理最简单、最小规模的问题，不涉及进一步的递归调用，防止无限循环。
- **递归情形（Recursive Case）**：将原问题分解为一个或多个更小的子问题，并通过递归调用函数来求解这些子问题，最终将子问题的解组合成原问题的解。

### 2. 典型示例：计算阶乘
以阶乘函数 $ n! $ 为例：

- 数学定义：
  $$
  n! =
  \begin{cases}
  1 & \text{若 } n = 0 \text{（基础情形）} \\
  n \times (n-1)! & \text{若 } n > 0 \text{（递归情形）}
  \end{cases}
  $$

- 对应的递归实现（以 Python 伪代码表示）：
  ```python
  def factorial(n):
      if n == 0:           # 基础情形
          return 1
      else:                # 递归情形
          return n * factorial(n - 1)
  ```

### 3. 递归的执行机制
递归调用依赖于**调用栈（Call Stack）**。每次函数调用都会在栈中创建一个新的栈帧，保存局部变量和返回地址。递归调用按“后进先出”顺序执行：所有递归调用必须先到达基础情形，然后逐层返回，完成计算。

### 4. 递归的应用场景
递归广泛应用于以下领域：
- **分治算法**：如归并排序（Merge Sort）、快速排序（Quick Sort）。
- **树与图的遍历**：如二叉树的前序、中序、后序遍历。
- **动态规划**：某些问题的递归形式可作为自顶向下实现的基础（如斐波那契数列的递归+记忆化）。
- **语法解析**：上下文无关文法的递归下降解析器。

### 5. 递归的优缺点
| 优点 | 缺点 |
|------|------|
| 代码简洁、易于理解，适合描述自相似结构 | 可能导致大量重复计算（如朴素递归斐波那契） |
| 自然表达数学归纳定义的问题 | 空间开销大，深度过大可能引发栈溢出（Stack Overflow） |
| 简化复杂问题的分解过程 | 需仔细设计基础情形，否则导致无限递归 |

### 6. 尾递归优化（Tail Recursion Optimization）
当递归调用是函数执行的最后一个操作，且其结果直接返回时，称为**尾递归**。某些编程语言（如 Scheme、Haskell）或编译器可将其优化为循环，避免栈空间浪费。例如：

```scheme
(define (factorial n acc)
  (if (= n 0)
      acc
      (factorial (- n 1) (* n acc))))
```

### 结论
递归是一种强大的计算范式，体现了**问题分解与自相似性**的思想。尽管在性能上可能不如迭代高效，但其在表达力和理论清晰度上具有显著优势。理解递归对于掌握算法设计、数据结构和编程语言理论至关重要。

【角色 2：儿童教育者】
好呀！我们用一个有趣的小故事来解释“递归”吧！

想象一下，你拿着一个小镜子，再对着另一面大镜子。咦？你看到了什么？

你会看到你的脸，
然后在镜子里的镜子里，又看到你的脸，
再往里看，还有一个小小的你，
再往里，还有一个更小的你，……
哇！好像永远看不到头，是不是？

这就像“递归”！

**递归就是：自己里面又装着自己，一次比一次小一点点，直到某个地方停下来。**

再打个更有趣的比方：
你有一本魔法故事书，封面写着：“先读完这本书，再睡觉。”

你翻开第一页，上面写着：“先读完这本书，再睡觉。” —— 哎呀，和封面一样！
再翻一页，还是这句话……一直到某一页，写着：“现在你可以睡觉啦！”

这本书一直在叫你“读完这本书”，也就是说，它在“自己叫自己”，这就叫**递归**！
但它最后给你一个“现在可以睡觉啦！”，这叫**停止的条件**，不然你就永远读下去啦！

所以，**递归就是：自己做一件事，先叫自己做一遍，再做下一步，直到说“好啦，停下来吧！”**

✨ 小结：
- 递归 = 自己里面又用到自己（像镜子套镜子）。
- 一定要有一个“停下来”的信号，不然就转晕啦！

## 🎯 Python 常见内置数据类型（Built-in Types）

Python 有几种**核心数据类型**，我们按类别来介绍：

---

### 1️⃣ 数字类型（Numeric Types）

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数（没有小数点） | `5`, `-3`, `1000` |
| `float` | 浮点数（带小数点） | `3.14`, `-0.5`, `2.0` |
| `complex` | 复数（实部 + 虚部） | `2 + 3j`（较少用） |

📌 小知识：
```python
type(10)      # <class 'int'>
type(3.14)    # <class 'float'>
```

---

### 2️⃣ 布尔类型（Boolean）`bool`

表示真假值，只有两个值：

- `True`（真）
- `False`（假）

💡 注意：首字母大写！

```python
is_student = True
is_adult = False
print(type(is_adult))  # <class 'bool'>
```

> 🔎 布尔值通常来自比较或逻辑运算：
> ```python
> print(5 > 3)  # True
> print(1 == 2) # False
> ```

---

### 3️⃣ 字符串（String）`str`

表示文本，用 **单引号 `'`、双引号 `"` 或三引号 `'''`** 包裹。

```python
name = "小明"
message = 'Hello, Python!'
multi_line = """这是
多行
字符串"""
```

📌 常用操作：
```python
text = "Python"
print(text[0])        # P（索引从 0 开始）
print(len(text))      # 6（长度）
print(text.upper())   # PYTHON
print(text + " 学习")  # Python 学习（拼接）
```

---

### 4️⃣ 列表（List）`list`

有序、可变（可以修改）、允许重复元素的集合。

```python
fruits = ["苹果", "香蕉", "橘子"]
numbers = [1, 2, 3, 2, 4]
```

📌 常用操作：
```python
fruits.append("葡萄")   # 添加元素
print(fruits[0])        # 苹果（索引访问）
fruits[1] = "芒果"       # 修改
print(len(fruits))      # 4（长度）
```

✅ 适合：存储一系列变化的数据（如购物清单）

---

### 5️⃣ 元组（Tuple）`tuple`

有序、**不可变**（创建后不能修改）的集合。

```python
point = (3, 5)
colors = ("红", "绿", "蓝")
```

📌 特点：
- 比列表更快
- 可作为字典的键（list 不行）
- 用圆括号 `()` 或不加括号

```python
print(point[0])  # 3
# point[0] = 4   # ❌ 错误！不能修改
```

✅ 适合：表示坐标、RGB 颜色等固定结构

---

### 6️⃣ 集合（Set）`set`

无序、**不重复**、可变的集合。用 `{}` 或 `set()` 创建。

```python
unique_nums = {1, 2, 3, 2, 1}  # 自动去重 → {1, 2, 3}
```

📌 常用操作：
```python
unique_nums.add(4)
unique_nums.remove(1)
print(3 in unique_nums)  # True（快速查找）
```

✅ 适合：去重、数学集合运算（并集、交集）

---

### 7️⃣ 字典（Dictionary）`dict`

存储**键-值对（key-value pairs）**，像一个真实词典。

```python
student = {
    "name": "小明",
    "age": 18,
    "is_student": True
}
```

📌 常用操作：
```python
print(student["name"])           # 小明
student["age"] = 19              # 修改
student["city"] = "北京"          # 新增
print("name" in student)         # True（检查键是否存在）
```

✅ 适合：表示结构化信息（如用户资料、配置）

---

## 🔍 如何查看数据类型？

使用 `type()` 函数：

```python
print(type(10))           # <class 'int'>
print(type("hello"))      # <class 'str'>
print(type([1,2,3]))      # <class 'list'>
```

或者判断是否为某种类型：

```python
isinstance(10, int)       # True
isinstance("abc", str)    # True
```

| 类型 | 关键字 | 是否可变 | 是否有序 | 示例 |

> ✅ 可变 = 可修改；❌ 不可变 = 创建后不能改
