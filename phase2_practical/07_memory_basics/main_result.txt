示例 2：使用 InMemorySaver 添加内存
======================================================================

第一轮对话：
Agent: 你好，张三！很高兴认识你。有什么我可以帮你的吗？😊

第二轮对话（同一个 thread_id）：
Agent: 你叫张三。😊

关键点：
  - Agent 记住了第一轮对话！
  - checkpointer 自动保存对话历史
  - thread_id 用于区分不同的会话

======================================================================

- 姓名：张三
- 年龄：25岁
- 职业：工程师

如需进一步帮助，请随时告诉我！

轮次 4:
用户: 我多大来着？

客服: 您今年25岁。需要我帮您查询其他信息吗？

关键点：
  - Agent 记住了用户的 ID
  - Agent 记住了查询的结果
  - 实现了流畅的多轮对话
