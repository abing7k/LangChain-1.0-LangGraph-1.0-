# LangChain 1.0 & LangGraph 1.0 
（附22个实战模块 + 3大项目完整源码）

课程亮点
 最新版本：基于2025年10月发布的LangChain 1.0正式版，使用最新的create_agent API，告别过时教程。
 系统全面：22个核心模块 + 3个综合项目，循序渐进掌握AI Agent开发全栈技能。
 开箱即用：完整可运行代码，中文注释，UTF-8编码，无需二次调试。
 实战导向：文档问答、智能客服、研究助手等真实项目，涵盖内存管理、持久化、中间件等生产级技术。
 零成本学习：免费API使用指南（Groq、Pinecone），降低学习门槛。
